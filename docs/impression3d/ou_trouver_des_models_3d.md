# Où trouver des models 3d ?

Le moyen le plus facile pour débuter dans l'impression 3D consiste à trouver des objets 3D sur internet gratuitement.
Ils se présentent habituellement sous la forme de fichiers au format .stl, .obj, .3mf, .step. 
Parcourez les sites pour decouvrir de nombreuse posbilitées.  

### <a href="https://www.makerworld.com/" target="_blank" rel="noopener noreferrer"> Makerworld </a>
Plateforme de Bambu Lab, nessecite une inscription. 
Trés grosse communauté,  les fichier sont prés parametrer pour les Bambulab  
La Partie Makerlab permet de générer des modèles 3D à partir de simples photos, de descriptions textuelles ou de paramtre pres defini.

  


### <a href="https://www.printables.com/" target="_blank" rel="noopener noreferrer"> Printables </a>
Plateforme de Prusa. Fichiers **STL/3MF** avec profils PrusaSlicer prêts à l'emploi, souvent compatibles multi-marques (Bambu, Creality...). Vérification anti-bot type quiz ("Give a Cookie") avant téléchargement. Bon niveau de documentation technique (support requis, orientation, réglages). Concours réguliers, utile pour projets pédagogiques thématiques.

###  <a href="https://www.thingiverse.com/" target="_blank" rel="noopener noreferrer"> Thingiverse </a>
La plus ancienne bibliothèque communautaire (backend historique MakerBot). Format **STL** dominant, fichiers sources parfois fournis (STEP, F3D, SCAD). Intègre le **Customizer**, une app OpenSCAD paramétrique permettant de générer des variantes sans logiciel de CAO — pratique pour initier des élèves à la modélisation paramétrique. Aucune vérification qualité avant publication : à filtrer avant impression en atelier.

## Autres ressources

###  <a href="https://cults3d.com/fr" target="_blank" rel="noopener noreferrer"> Cults </a>
Plateforme française, fichiers **STL/STEP** gratuits et payants. Licences explicitement indiquées (usage personnel vs commercial), important pour un cadre pédagogique/institutionnel. Interface en français, utile pour des supports de cours.

###  <a href="https://www.myminifactory.com/fr" target="_blank" rel="noopener noreferrer"> MyMiniFactory </a>
Label **"Guaranteed to print"** : chaque modèle est testé avant publication, réduit le taux d'échec en atelier. Filtrage par machine/filament. Bibliothèque orientée figurines et jeux de plateau.

###  <a href="https://www.yeggi.com/" target="_blank" rel="noopener noreferrer"> Yeggi </a>
Métamoteur de recherche, n'héberge aucun fichier : il indexe et redirige vers Thingiverse, Cults, MyMiniFactory, etc. Utile pour une recherche croisée rapide avant de choisir une source fiable.

### <a href="https://pinshape.com/" target="_blank" rel="noopener noreferrer"> Pinshape </a>
Marketplace mixte gratuit/payant orientée design produit et objets fonctionnels du quotidien.

### <a href="https://www.youmagine.com/" target="_blank" rel="noopener noreferrer"> YouMagine </a>
Plateforme open source liée à l'écosystème Ultimaker/Cura. Licences copyleft favorisées, cohérent avec une logique de partage libre en fablab.

### <a href="https://3dexport.com/" target="_blank" rel="noopener noreferrer"> 3DExport </a>
Catalogue orienté rendu 3D/jeu vidéo (formats **OBJ, FBX**) avec une section imprimable en **STL**. Moins adapté aux débutants, plus proche d'un usage pro/CAO.

### <a href="https://www.cgtrader.com/" target="_blank" rel="noopener noreferrer"> CGTrader </a>
Marketplace professionnelle VFX/jeu vidéo majoritairement payante, avec section imprimable. Exigences de topologie/maillage plus techniques que les sites grand public.

### <a href="https://sketchfab.com/" target="_blank" rel="noopener noreferrer"> Sketchfab </a>
Visualiseur WebGL interactif, pas dédié à l'impression 3D. Utile pour des scans 3D/photogrammétrie ; téléchargement et impression possibles selon la licence du modèle, à vérifier au cas par cas.
